# NIR Spectroscopy Preprocessing

## Overview

This repository contains Python implementations of commonly used preprocessing techniques for Near Infrared (NIR) spectroscopy data. These methods are widely used in chemometrics and machine learning to improve spectral quality before regression and classification.

## Research Areas

- Near Infrared Spectroscopy (NIR)
- Chemometrics
- Machine Learning
- Deep Learning
- Food Quality Assessment
- Agricultural Product Analysis

---

## Implemented Preprocessing Methods

- Standard Normal Variate (SNV)
- Multiplicative Scatter Correction (MSC)
- Savitzky–Golay Smoothing
- First Derivative
- Second Derivative
- Mean Centering
- Normalization
- Baseline Correction
- PCA Visualization
